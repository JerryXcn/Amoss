Amoss — Third-party components

Amoss includes a scrcpy 5.0.1 client with a native SwiftUI bottom toolbar and
viewport/input integration. The matching official server and ADB are unmodified
except local code signatures. Modified client and toolbar sources are included.
No Homebrew, Android SDK, Java, or separate installation is required at runtime.

The Amoss scrcpy client statically incorporates FFmpeg 9.0.2, SDL 3.4.18 and
dav1d 1.5.4. Corresponding source archives, checksums, complete modified client
sources and build recipes accompany the installer in its "Third-party sources"
folder. License texts are included in this directory. FFmpeg, SDL and dav1d
source code is unmodified. The original release's libusb 1.0.30 source and
license are also preserved; Amoss disables client AOA/OTG functionality.
