# Changelog / 更新记录

## 0.5.0 — Prepared for first public release / 首次公开发布准备

- Add Simplified Chinese and English, system-language fallback and immediate language switching, including mirror controls.
- License Amoss original code under Apache-2.0; retain third-party licensing and corresponding sources.
- Add bilingual documentation, contribution/security/privacy guidance and GitHub CI/issue configuration.
- Pin every upstream source checksum; add environment checks, source/build matching and normalized source archives.
- 中英文切换、系统语言回退与镜像控制栏翻译；补齐开源材料，改进构建校验与安装包来源一致性。

The entries below describe local development milestones, not prior GitHub releases.
以下为本地开发里程碑，不代表已在 GitHub 发布。

## 0.4.2

- Expand About Amoss with the name's meaning, version, features and open-source acknowledgements.
- 丰富关于窗口、名称释义和开源致谢。

## 0.4.1

- Reduce idle clipboard polling; respond to sleep, wake and Low Power Mode.
- 降低空闲检查频率，处理睡眠、唤醒与低电量模式。

## 0.4.0

- Introduce background bidirectional clipboard sessions with per-device switches and reconnection.
- 增加不依赖镜像的后台双向剪贴板与设备级开关。

## 0.3.0

- Adopt menu bar launch, device/app submenus, recent apps and window management.
- 默认菜单栏驻留，增加设备、应用子菜单和窗口管理。

## 0.2.0–0.2.1

- Add independent Android application windows and expandable per-device app lists.
- 增加独立应用窗口及设备下的二级应用列表。

## 0.1.0–0.1.2

- USB discovery, device mirroring, foldable display selection, native system controls and panel-off mirroring.
- USB 发现、设备镜像、折叠屏选屏、原生系统操作栏和熄屏镜像。
